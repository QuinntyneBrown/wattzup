Iconography

Every icon is a Lucide outline drawn inline, so it inherits the text colour and needs no network. Icons support a label; they rarely replace one.

Overview

Telo Ride uses Lucide 0.577, the set the design's React code imports. Each icon is copied into the markup as inline SVG: there is no icon font, no sprite and no network request, and the icon picks up the colour of the text around it.

  • One style. Outline, 2px stroke, round caps and joins, drawn on a 24-unit grid. The .icon class sets all of it, so the SVG carries only its paths.
  • Icons mean one thing. bluetooth is always the bike connection, flame is always the streak, star is always earned progress (WCAG 3.2.4).
  • Beside words, not instead of them. Most icons sit next to a visible label and are hidden from assistive technology. Icon-only controls are rare and always named.
  • The logo mark is not an icon. It has its own stroke, colours and rules: see Lockup.

Grid and stroke

PropertyRule
CanvasviewBox="0 0 24 24" on every icon; artwork keeps at least 1 unit from the edge.
Strokestroke-width: 2, stroke-linecap: round, stroke-linejoin: round, fill: none. Set by .icon; never set on the SVG.
Colourstroke: currentColor. The icon takes the text colour of its parent; tint it by colouring the parent or adding a .text-* helper.
FillOnly stars fill, and only when earned (.stars .icon.is-earned fills gold). A filled shape means “yours”.
ScalingThe stroke scales with the icon (2 units of 24). At 12px it draws 1px; at 40px about 3.3px. That is why 12px icons appear only beside 12px text.

Colour

An icon is the colour of its text unless it carries a status. The status colours come from the -fg tokens on Color, so they pass 3:1 in both themes.

Echelon EX-5s 4 Bluetooth is off Neon Docklands is open
Echelon EX-5s 4 Bluetooth is off Neon Docklands is open
  • Volt (--color-volt-fg): the bike is connected, you are ready. Volt marks “you” and “go”.
  • Heart (--color-heart-fg): the bike is gone, Bluetooth is off. Always with words.
  • Warn (--color-warn-fg): the streak flame, browser notices.
  • Gold (--color-gold-fg, fills --color-gold): earned things only. Stars, unlocks.
  • Faint (--color-faint): bots, unearned stars, chevrons. Decorative or secondary.

Accessibility

  • Non-text contrast (1.4.11). An icon that carries meaning on its own (the bot mark, status icons, steppers) needs 3:1 against its background. The -fg status tokens and --color-faint meet it in both themes; see the pairs on Color.
  • Use of colour (1.4.1). A red bluetooth icon never stands alone: “Bluetooth is off” or “Lost the bike” is always in text.
  • Target size (2.5.8). The icon is not the target. An icon-only button is at least --control-height-sm (36px) square, and 48px (--target-ride) when pressed mid-ride. See Responsive.
  • Forced colours. currentColor strokes follow the system text colour automatically; never hard-code a stroke.

Tokens

Icons introduce no tokens of their own. Sizes read the spacing scale (--space-3 to --space-10, documented on Spacing), colours read the text and status tokens on Color, and the spinner reads --duration-loop on Motion.
