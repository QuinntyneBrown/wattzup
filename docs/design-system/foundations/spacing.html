Foundation

Spacing

Tailwind’s 4px scale, with four half steps for the tight insides of components. Insides stay small and fixed; space between grows with what it separates.

WCAG 2.2 AAStatus: stableSince v1.0
  • Overview
  • Scale
  • Half steps
  • Inside and between
  • Usage
  • Tokens

Overview

Spacing is Tailwind's scale, the one the design was drawn with: one unit is 4px and the token number is the Tailwind number (--space-4 is p-4, 16px). Four half steps sit on a 2px grid for the tight insides of components. Spacing never scales with the viewport; a breakpoint swaps one token for a larger one.

Two kinds of space: inside a component (padding, the gap between an icon and its label) and between components (the gap between cards, sections and the page edge). Insides stay at or below --space-7; betweens start at --space-3 for tiles in a grid and reach --space-14 between page columns.

Scale

Twenty-eight steps. The bars are drawn at true size (wide steps are clipped on narrow screens).

Half steps

--space-0-5 (2px), --space-1-5 (6px), --space-2-5 (10px) and --space-3-5 (14px) are the design's gap-1.5, py-2.5 and h-3.5. They exist because a 14px label inside a 36px control needs finer steps than 4px to centre and to sit close to its icon.

  • Half steps sit on a 2px grid and are for the inside of a component only: pill padding, the icon-to-label gap in back links and banners, the header's 10px block padding, the 14px small icon.
  • Never use a half step between components, sections or columns. Those use whole steps from --space-3 up.
  • If a new component seems to need 18px or 22px, it needs a whole step and a rethink, not a new half step.

Usage

  • Pick from the scale; if a value is not on it, it is not a spacing decision (a width or a size belongs to a layout or component token).
  • Space between grows with the size of what it separates: 12px between tiles, 40px between sections, 56px between columns.
  • Change spacing at a breakpoint by swapping tokens in a min-width query (--space-5 → --space-7), never with vw.
  • Use gap on the parent rather than margins on children; the mocks' mt-* on a section's first child is the exception for one-off rhythm.
  • Negative margins only to optically align an edge control (.icon-btn--edge, the header nav's -4px).
