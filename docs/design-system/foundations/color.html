Color

Ink, panel and raised; one signal orange for you and the primary action; gold only for what you earned. Every colour token, both themes, and every contrast pair checked live.

Overview

Telo Ride is a dark product. Riders sit in a dim room in front of a big screen, so the canvas is near-black ink, cards are one step lighter, and colour is spent on very few things: signal orange for you and the primary action, gold for what you earned, and four signal hues for rest, heart, warning and success. Light is an addition for daytime and print: paper instead of ink, with deep variants of every accent so text still reads.

The design's own theme names (--color-ink, --color-panel, --color-volt…, the Tailwind theme in the source: bg-ink, text-volt) are the canonical semantic tokens. Role names (--color-bg-canvas, --color-fg-muted, --color-danger-bg) alias them so tooling and newcomers can read the system by role. Primitives (--palette-*) are read only by semantic tokens.

Primitive palette

Every raw value lives here once. The dark ramp is the design's palette; the light ramp is the addition, warm paper rather than cool grey so the orange still feels at home. Components never read a primitive: a theme swaps which primitive a semantic token points at.

Dark palette (the design)

ink · panel · raised · line · steel · faint · muted · bone. Steel (#636873) was the design's "faint"; it read 3.2:1 on panels, so it now draws strong borders and disabled text and faint moved up to #878d97.

Light palette (an addition)

paper panel · paper · paper raised · paper line · paper steel · paper faint · paper muted. Text on paper is --palette-ink.

Accents

Deep accents for paper

On paper the bright accents fail as text (signal orange is 2.7:1 on paper raised), so each has a deep twin used for text, links, icons and focus in the light theme. Fills keep the bright value in both themes.

Semantic roles

The design's names, resolved in both themes. Surfaces step up in lightness on dark (ink, panel, raised) and use paper, panel white and warm grey on light. Text has three levels plus disabled; every level passes 4.5:1 on every surface.

Volt is you; gold is earned

Volt is you and the primary action; gold is only for earned things. This is the one colour rule every screen keeps. Volt (signal orange) marks the rider's own dot on the map and board, the selected option and the single primary button in a view. Gold marks things the rider has earned: the level badge, the XP bar, stars, "Opens Neon Docklands", the unlock banner and its Ride it button. Nothing else is orange or gold.

Adding a brand theme

A partner skin (a gym's own orange, a club's colours) is a third theme, not a fork. It overrides semantic tokens only; components and their component tokens never change.

  1. Add primitives for the brand hue and its deep twin to the primitives block: --palette-partner, --palette-partner-deep.
  2. Add a theme block that re-points the accent family: --color-volt, --color-volt-hover, --color-volt-dim, --color-volt-fg, --color-volt-fg-hover, --color-volt-subtle, --color-volt-subtle-hover, --color-focus-ring and --jersey-you. Leave gold alone: earned is earned in every skin.
  3. Pick --color-on-fill so the label on the brand fill passes 4.5:1, and make sure the brand fill passes 3:1 against --color-ink and --color-panel.
  4. Run check_contrast.py tokens/tokens.css; every pair in contrast-pairs.json is checked in every theme block. Then regenerate tokens.json.
[data-theme="partner"] {
  color-scheme: dark;
  --color-volt: var(--palette-partner);
  --color-volt-fg: var(--palette-partner);
  --color-focus-ring: var(--palette-partner);
  --jersey-you: var(--palette-partner);
  /* …the rest of the volt family, then every dark-theme token this skin keeps */
}

See Theming for how themes nest and how tokens.json carries them.

Usage

  • Read semantic tokens (--color-panel or --color-bg-surface), never --palette-* and never a raw value.
  • Use the -fg variant for any accent set as text or an icon (--color-heart-fg), the bare name for fills (--color-heart). On dark they differ only for heart; on paper all of them do.
  • One volt fill per view. Selected states use --color-raised (segmented, nav) or --color-volt-subtle (rows), not a second orange button.
  • Gold only for earned: XP, levels, stars, unlocks. A gold button means "you unlocked this, go".
  • --color-line is decorative. A border that tells the rider where to click or type uses --color-line-strong.
  • Text on photos and video is --color-on-photo on --color-scrim-strong, in both themes; the photo does not change with the theme.
  • Translucent white overlays from the source (bg-white/10) are written as color-mix(in srgb, var(--color-fg) 10%, transparent) so they stay visible on paper.
  • Never signal state with colour alone: pair it with an icon, a word or a shape (the delta "-47 W" carries its sign).
