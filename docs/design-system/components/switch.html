Switch

A switch turns one setting on or off the moment it is pressed: "Ride along to a video" shows the video player, "Log every packet" starts recording Bluetooth traffic. It is always a labelled row, never a bare track.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Use .switch (role="switch", aria-checked) for a setting that takes effect immediately, with no Save. Put it in a .switch-row with a visible label and, where the effect is not obvious, a one-sentence description. Use a checkbox for a yes/no that waits for a form submit, and a segmented control when the two states have names of their own.

Profile's .setting-row ("Echelon EX-5s · Connected · diagnostics") looks like a settings row but opens another screen: it is a link with a chevron, not a switch. Never put a switch inside a .setting-row link.

Anatomy

  1. Label14px medium; names the setting, not the action.
  2. Description (optional)14px muted; what turning it on does or costs.
  3. Track44 × 24px (--space-11 × --space-6), full radius. Off: raised with a 1px --color-line-strong inset edge; on: volt.
  4. Thumb20px circle, 2px inset. Off: --color-fg at the start; on: --color-on-fill at the end.

Sizes

One size: 44 × 24px. The track sits in a row at least 40px tall, so the touch target is the row, not the track alone.

States

Responsive behaviour

WidthRule
360 (base)The switch stays at the end and keeps its size; label and description wrap beside it, and the switch aligns to the label's first line.
640 (sm)No change; Custom Setup's 36rem column keeps the switch close to its label.
1024 (lg)No change. In a very wide row, use --start so the switch is not far from its label.

Theming

The track reads --color-raised (off) and --color-volt (on), the thumb --color-fg / --color-on-fill. The off track's inset --color-line-strong edge is what makes it meet 3:1 against the page in both themes; raised alone is 1.2:1 on ink.

Accessibility

Role and pattern

<button type="button" role="switch" aria-checked>, labelled by the visible label (aria-labelledby) and described by the description (aria-describedby), per the APG Switch pattern. Do not change the label with the state ("On"/"Off"): the state is announced from aria-checked.

Keyboard

KeyAction
TabFocuses the switch.
Space / EnterToggles it.

Focus

The shared 2px ring at a 2px offset around the pill.

Labelling

Every switch needs a visible label it is tied to. Clicking the label text does not toggle a button switch, so keep the label close; or wrap row and switch in one <label> around a native input type="checkbox" role="switch" where the whole row should be pressable.

Description

Motion

Thumb slides and track fades over --duration-fast; instant under reduced motion. The thumb's position, not only the colour, shows the state.

Touch

The track is 44 × 24 and sits in a row with 8px padding; give the switch at least 24px clear on each side so it is not pressed by mistake.

Content

  • Label the setting in sentence case as a positive statement: "Ride along to a video", "Log every packet".
  • Use the description for the effect or cost: "Plays in sync on the dashboard", "it uses memory".
  • Never "Enable …" / "Disable …": the switch already says that.
