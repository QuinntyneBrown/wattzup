Stat

One number, read at a glance: tabular Barlow numerals, the unit beside them, and a change that says whether it was better.

Overview

A stat is one number worth reading on its own: a label, a Barlow Condensed numeral with its unit, and optionally a hint or a change. Class Ride's bike panel is the model (.class-stat: "Power 108 W · On target"); Race Setup's facts (.setup-fact__number) and Profile's headline ("23 rides · 412 km · 4-day streak") are smaller cousins. .stat is the generic block with sizes, a boxed variant and deltas.

  • Live ride readouts (watts, cadence, heart rate during a ride, the HUD) belong to Ride readout, which handles updates and timers.
  • A list of labelled values about one thing is a description list.

Anatomy

  1. Label12px --color-muted, above the number.
  2. NumeralBarlow Condensed bold, tabular figures (tnum), 18–48px.
  3. Unit14px --color-faint, baseline-aligned, after a 4px gap.
  4. Delta or hint12px; a delta has an arrow, a sign in words and a colour by meaning (better ok, worse heart, on target volt).

States

Stats are read, not pressed: no pointer or focus states. "Disabled" is a stat with no data (an em dash and a reason); loading pulses the number's box with aria-busy="true".

Responsive behaviour

  • 360px: .stats is two columns; a .class-stat--wide spans both.
  • 640px: .stats fits as many 9rem columns as the row allows.
  • 768px: Class Ride's bike panel goes to one row (segment, power, cadence, resistance).
  • Numerals never wrap or shrink; units stay on the same line.

Theming

.stat { --stat-number-size: var(--font-size-2xl); --stat-label: var(--color-muted); }
.stat--lg { --stat-number-size: var(--font-size-5xl); --stat-number-line: var(--line-height-none); }

Delta colours use -fg tokens (green-deep, red-deep, signal-deep on paper) so a delta passes 4.5:1 in light as well.

Accessibility

Role and pattern

A group of text: label, number, unit. Put stats in a <dl> when several sit together, or keep the label and value in one element so they read as "Power 108 W". No ARIA widget.

Keyboard

KeyAction
TabSkips stats.

Focus

None.

Labelling

Read as one phrase: "Time 26:38, 0:32 faster than your best". Arrows are aria-hidden; the words carry the direction. Units are spelt as screen readers expect ("rpm", "km", "W"). A missing value reads "No data yet", not "dash".

Motion

Loading pulses over --duration-pulse; reduced motion holds it flat. Values that change do not animate (counting up would delay reading).

Touch

Not a target.

Content

  • Labels: one noun ("Power", "Cadence", "Distance").
  • Numbers: tabular, thousands with commas ("3,870 km"), times m:ss.
  • Deltas: say better or worse in words ("0:32 faster than your best", "18 s off the podium"); never just "−0:32".
  • Gold only for earned numbers (level, XP).
