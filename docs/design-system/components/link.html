Link

Links go somewhere; they never change anything. Telo Ride has three: the muted standalone link with an arrow ("All maps →"), the back link ("← Maps") and the underlined link inside a sentence.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Use a link when activating it opens another page or another site. Use a button when it does something (starts, saves, pairs, opens a dialog), even if a page change follows.

  • More link (.more-link): at the end of a section head, leading to the full list: "All maps →", "All classes →".
  • Back link (.back-link): up one level from a focused screen: Race Setup's "← Maps". Kit name for .setup-header__back.
  • Inline link (.link): inside running text, always underlined: "Half a second later Telo Ride moves on to Home."
  • External link: any of the above with .link__external after the label when it leaves Telo Ride (YouTube, help).

Anatomy

  1. Label14px regular, --color-muted, turns --color-fg on hover. Names the destination.
  2. Direction icon16px arrow, 4px gap (6px on the back link), aria-hidden: → forward, ← back, ↗ external.

Responsive behaviour

WidthRule
360 (base)More links stay on the section head's baseline (they never wrap: white-space: nowrap); a long section title wraps instead. Inline links wrap with their sentence.
640 (sm)No change.
1024 (lg)No change; the back link sits in the setup header beside the lockup at every width.

Theming

Standalone links read --color-muted and --color-fg. Inline links read two component tokens, --link-fg and --link-fg-hover, which default to --color-volt-fg and --color-volt-fg-hover; the quiet and muted variants re-point them. In light, volt text deepens to --palette-signal-deep (5.1:1 on paper) because signal orange itself reads only 2.9:1 on paper.

Accessibility

Role and pattern

Native <a href>; see the APG Link pattern. Never a <span> with a click handler, and never role="tab" or role="radio" on a link.

Keyboard

KeyAction
Tab / Shift+TabMoves to and from the link.
EnterFollows the link. (Space scrolls the page; links do not respond to it.)

Focus

The shared 2px ring at a 2px offset around the label and icon; .more-link and .link have a small radius so the ring follows the text.

Labelling

The text names the destination and makes sense alone: "All maps", "All classes", "Maps". Arrows are aria-hidden. External links add a visually hidden "(opens in a new tab)" when they use target="_blank".

Inline links are underlined, so they are found without colour (1.4.1). Standalone links are set apart by position and arrow, not colour.

Motion

Colour eases over --duration-fast; instant under reduced motion.

Touch

Standalone links are 20px of text; give them 24px of row height (the section head does) and keep 8px from any neighbour. The back link adds 4px × 8px padding in the setup header.

Content

  • Name the place, not the act: "All maps", "Maps", "Home". Never "Click here" or "Learn more".
  • Forward links use "All …" for the full list of what the section previews.
  • Back links name the parent screen exactly as its title or nav label reads ("Maps", not "Back").
  • Inline links are the few words that name the destination, not the whole sentence.
