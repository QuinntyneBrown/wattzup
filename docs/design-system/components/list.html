List

A column of like things, one per row: rides you did, maps you can open, settings you can change.

Overview

A list is a column of like things, one per row, read top to bottom. Telo Ride draws three: Profile's Recent rides (.recent__row: icon, title, detail, XP), Map Select's path (.map-path of .map-row: thumbnail, name, facts, stars or unlock goal) and Profile's Settings rows (.setting-row). .list is the generic block they share: simple, two-line, with an icon or avatar, interactive, with dividers.

  • Use a list when each row is one thing and the reader scans for one of them.
  • Use a table when they compare the same columns across rows.
  • Use the leaderboard for a ranked list of riders.
  • Use a description list for label and value pairs about one thing.

Anatomy

  1. Leading icon or avatar16–20px lucide icon in --color-muted, or a jersey dot; aria-hidden.
  2. TitleMedium weight, one line, truncates with an ellipsis; the accessible name of the row action.
  3. Detail14px --color-muted; facts joined with " · ".
  4. TrailingA chevron (row opens something), a value (gold XP numeral) or a short meta ("DE · Lv 4").
  5. Row.list__item, or .list__action when the row is a link or button: 44px minimum, --radius-lg hover fill, 60% hairline between rows.

Sizes

Two densities. Default rows pad 12px top and bottom (--list-py: var(--space-3)) with a 16px gap; dense rows pad 8px with 12px. Interactive rows never drop under 44px whatever the density. Map rows have their own size: 96px thumbnails below 640px, 176px from 640px.

  • Disabled: a locked map is a <button disabled> that still shows its goal; it stays in the list so the path makes sense.
  • Current: aria-current="page" (or "true") on the action marks the row for where you are; accent-subtle fill, volt title.
  • Loading: use composed skeleton rows with the same grid as the real row.
  • Empty: a compact empty state in place of the list ("Nothing yet. Your first race shows up here, with the XP it earned.").

Responsive behaviour

  • 360px: one column; titles and details truncate with an ellipsis rather than wrap, so rows keep one height; map rows use a 96px thumbnail and hide the chevron.
  • 640px: map rows grow to a 176px thumbnail and show the chevron; settings rows unchanged.
  • 1024px: lists sit in their column of the two-column layouts (recent rides in Profile's main column, settings in its 340px aside) and never stretch wider than the column.
  • Trailing values never wrap under the title; if the row is too narrow, the title truncates first.

Theming

.list {
  --list-border: color-mix(in srgb, var(--color-line) 60%, transparent);
  --list-hover: var(--color-raised);
  --list-selected: var(--color-accent-subtle);
  --list-py: var(--space-3); --list-gap: var(--space-4);
}

On a raised well (inside a dialog) override --list-hover: var(--color-raised-hover). Light theme swaps the panel, line and text tokens; the XP numeral uses --color-gold-fg, which deepens to gold-deep (#8a6100) on paper so it stays readable.

Accessibility

Role and pattern

<ul> or <ol> (ordered when the order means something: the unlock path). Interactive rows contain one <a href> or <button>; no ARIA listbox, because rows navigate rather than select. See the APG structural roles guidance on lists.

Keyboard

KeyAction
Tab / Shift+TabMoves from row action to row action. Disabled (locked) rows are skipped.
EnterFollows a link row (opens Race Setup, Diagnostics).
SpaceActivates a button row.

Focus

The ring wraps the whole row action (2px --color-focus-ring, 2px offset, the row's --radius-lg or --radius-xl for map rows).

Labelling

The row's text is its name: "Old Town Criterium 14.2 km · 140 m climbing · Easy 1 of 3 stars Best 27:10". Keep it short by marking decorative parts aria-hidden (icons, chevrons, path dots). Locked rows add ", locked" (and ", your next unlock") in visually hidden text. The list gets a label when a heading does not already introduce it.

Motion

Row fill and title colour fade over --duration-fast; zero under reduced motion.

Touch

Row actions are at least 44px tall (--target-comfortable); map rows are 70px or more. The whole row is the target, so nothing relies on hover.

Content

  • Title: the thing's name, as it appears everywhere else ("Old Town Criterium", "30 Minute HIIT Cardio").
  • Detail: facts in a fixed order joined with " · ": when, mode, result ("Yesterday · 5th of 10 · 27:10").
  • Relative days up to a week ("Yesterday", "Mon"), then dates.
  • XP is signed and gold ("+262"); never put other numbers in gold.
  • Locked rows say how to open them as a sentence fragment starting with a verb ("Earn 2★ on Cliffside Coast", "Reach rider level 10").
