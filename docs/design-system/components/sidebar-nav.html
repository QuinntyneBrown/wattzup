Sidebar navigation

A column of links beside the content for screens with many sections, such as a future settings or profile area. The product does not use it yet; it is designed here so the first screen that needs it looks like Telo Ride.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Telo Ride navigates with one top bar and has no sidebar today. A sidebar earns its place only when a single area grows more sections than a row of tabs holds (about five) and people move between them often: Profile with settings for the bike, the account, data and privacy, for example. It never replaces the app header; it sits under it, inside the page.

  • Use it for sibling pages of one area that a rider revisits (Profile → Recent rides → Bike → Diagnostics).
  • Do not use it for the main destinations (Home, Race, Classes, Profile stay in the header), for steps of a flow, or on ride screens, where it would take width from the video and the readouts.

Anatomy

  1. Group heading12px semibold uppercase overline in --color-faint, widest tracking; names the list (aria-labelledby). Optional <summary> to collapse.
  2. Current marker2px volt bar on the left edge plus the raised fill; aria-current="page".
  3. Link36px row, 12px padding, 16px icon and 14px medium label in --color-muted; --radius-lg, raised on hover.
  4. Badge (optional)A .pill pushed to the end: a count or a short status.

Collapsible groups use <details>/<summary> (the chevron turns −90° when closed). Icon-only keeps each label as the link's accessible name and shows it as a tooltip on hover and focus.

Sizes

One size: 36px rows (--control-height-sm, the header's link height), 256px column (--layout-sidebar-width), 56px when collapsed to icons (--side-nav-collapsed-width). Rows grow with their label when it wraps on a narrow column; they never truncate a label mid-word.

Responsive behaviour

  • Under 1024px the sidebar becomes a single scrolling row of links under the page title, like the app header's nav row under 640px: headings hidden, groups run together, current link marked by the fill and a 2px volt bar underneath. No drawer and no menu button; Telo Ride has neither.
  • From 1024px (--layout-breakpoint-lg) it is a 256px column beside the content (.side-nav-layout, 48px gap), with group headings, and can collapse to icons.
  • The column does not scroll on its own unless it is taller than the viewport; then make it position: sticky; top: 0 inside .app__scroll.

Theming

Transparent on the page; links read --side-nav-fg (--color-muted), hover and current fill --color-raised, the current bar --side-nav-indicator (--color-volt-fg, which holds 3:1 against the raised fill in both themes). Override the --side-nav-* tokens on .side-nav to re-theme; for example a sidebar on a panel sets --side-nav-bg-current: var(--color-raised-hover) so the fill still steps up.

Accessibility

Role and pattern

A <nav> landmark named for its area (aria-label="Profile"), lists of links, the current one with aria-current="page"; collapsible groups are native <details>. This is the APG disclosure navigation pattern; it is not a menu or tree, so no arrow-key roving.

Keyboard

KeyAction
Tab / Shift+TabThrough group summaries and links in order.
EnterFollows a link.
Enter, SpaceOpens or closes a group (on its summary); toggles icon-only mode (on the collapse button).

Focus

Shared ring around the link's rounded row. On arrival at a new section, focus goes to that page's h1 or main, not back to the sidebar.

Labelling

Each list is labelled by its heading (aria-labelledby); in icon-only mode the label stays in the DOM, visually hidden, as the accessible name, and the tooltip repeating it is aria-hidden. Badges are read with the link ("Recent rides 23"); give a status badge words ("Connected"), never a bare dot.

Motion

Fill and text colour over --duration-fast; the group chevron turns over --duration-base with --ease-panel. Both instant with reduced motion.

Touch

36px rows; the scrolling row below 1024px is swipeable and each link is at least 44px wide.

Content

  • Links are nouns for places, sentence case: "Recent rides", "Diagnostics", "Custom workout".
  • Group headings are one word: "You", "Bike", "Ride".
  • Badges hold a count or a one-word status; never "New!".

Sources

Not in the mocks. Telo Ride uses a top bar only; no screen in docs/mocks has a sidebar, and the product does not use this component yet. It is designed from the kit's own decisions so the first screen that needs one stays in the family:

  • Row height, radius, muted → fg text and the raised current fill from the app header's nav links (pages/home/default).
  • Icon, title and chevron rows from Profile's settings list (pages/profile/default).
