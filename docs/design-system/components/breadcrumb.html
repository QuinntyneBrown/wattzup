Breadcrumb

A quiet trail that says where a page sits and lets the rider step back up. Telo Ride's flows are shallow and use a single back link today; the breadcrumb is ready for the first screen that is three levels deep.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Most Telo Ride screens are one step from the main nav, and their task header already carries one back link ("← Maps", "← Classes"). Add a breadcrumb only when a page is three or more levels deep and the rider may want any level in between: a class inside a length inside the library, or a diagnostics page inside a bike inside Profile.

  • Never on ride screens (Race, Class Ride, the custom ride): they have one way out and it asks first.
  • Never as the only navigation: it complements the app header, it does not replace it.
  • Below 768px it collapses to the parent alone, which is exactly the product's back link.

Anatomy

  1. Ancestor link14px muted, underlined on hover; 24px tall hit area.
  2. Separator14px chevron in --color-faint, aria-hidden; the list structure carries the order.
  3. Current page14px medium fg, not a link, aria-current="page"; truncates with an ellipsis if it must.

Responsive behaviour

  • Under 768px only the parent shows, with a left arrow: "← 30 min". It is the same thing as the task header's back link, so a phone sees one consistent pattern.
  • From 768px (--layout-breakpoint-md) the full trail shows with chevrons; it wraps between items if it must, never inside one.
  • Collapse to "first · … · parent · current" from four levels at any width.

Theming

Links read --breadcrumb-fg (--color-muted) and --breadcrumb-fg-hover (--color-fg); separators --breadcrumb-sep (--color-faint); the current page is --color-fg. No volt: a breadcrumb is orientation, not an action. Override the three tokens on .breadcrumb, for instance on a photo set all three to --color-on-photo.

Accessibility

Role and pattern

APG Breadcrumb: <nav aria-label="Breadcrumb"> around an <ol>; the current page has aria-current="page". Separators are aria-hidden SVGs, so a screen reader hears "Breadcrumb, navigation, list, 3 items".

Keyboard

KeyAction
TabThrough ancestor links (and the ellipsis button); the current page is not focusable.
EnterFollows a link; opens the ellipsis menu.
EscCloses the ellipsis menu and returns focus to it.

Focus

Shared ring around each link (4px radius, 4px side padding so the ring clears the text).

Labelling

The landmark is "Breadcrumb"; when a page has more than one (rare), name them apart. The ellipsis button says how many levels it hides and which: "Show 1 more level: Settings".

Motion

Colour eases over --duration-fast; nothing moves.

Touch

Links are 24px tall (the minimum) with 4px between items; the phone version is a single back link, so no small targets sit side by side where fingers are used.

Content

  • Use each page's own title, shortened only if it is long: "Classes", "30 min", "30 Minute HIIT Cardio".
  • Never include Home; the brand link is home.
  • No trailing separator, no "You are here".

Sources

Not in the mocks. No Telo Ride screen has a breadcrumb and the product does not use one yet; its flows are shallow and each task header carries one back link. This component is designed restrained so it can grow out of that link:

  • The phone form is the back link of pages/race-setup/default ("← Maps") and pages/class-start/default ("← Classes").
  • Type and colours follow the header's links (pages/home/default).
