Logo lockup

The mark and the wordmark together: the first thing in every header and the only place the product name is drawn rather than written.

Overview

The lockup is the Telo Ride logo: the mark (a crank turning inside a chainring) beside the wordmark TELO with the product name Ride in signal orange. It opens every screen header, so a rider always knows which app is holding the bike. Use it only as the brand: never as an illustration, a bullet or a loading spinner (use a spinner).

  • As the Home link in the app header on Home, Map Select, Classes and Profile.
  • Static in the focus headers that have no navigation: Race Setup, Race Lobby, Race, Results, Class Start, Class Ride and Connect Bike.
  • On a photo only where a header floats over the world or a video; it then uses the on-photo variant.
  • Mark only where a header has no room for the wordmark (Class Ride under 384px).

Anatomy

  1. RingA 300° arc, 6/48 stroke, --lockup-ring (--color-fg): ink on paper, bone on ink.
  2. CrankA line from the hub to the gap in the ring, --lockup-accent (--color-volt) in both themes.
  3. HubA filled circle, r 4.6 of 48, the same signal orange.
  4. Wordmark“TELO” in Barlow Condensed 800 italic, uppercase, tracking −0.01em.
  5. Product name“Ride” after a 0.18em gap, --lockup-product (--color-volt-fg).

Clear space

Keep clear space equal to half the mark’s height on every side (13px at medium, --space-3). Nothing else in the header comes closer: the header’s own 10px vertical padding plus the gap to the first nav link already give it. On a photo, the clear space also has no busy detail behind it.

Minimum size

The smallest lockup is small: a 24px mark and a 20px wordmark. Below that the italic counters close up and the crank reads as a smudge. When a header cannot fit small, drop the wordmark (.lockup--mark) and keep the mark at 24px; do not shrink further.

Theming

The lockup reads six component tokens declared on .lockup: --lockup-mark-size, --lockup-wordmark-size, --lockup-gap, --lockup-ring, --lockup-accent, --lockup-wordmark and --lockup-product. In the dark theme the ring and wordmark are bone on ink; in light they turn ink on paper. The crank and hub keep signal orange in both themes; the word “Ride” uses --color-volt-fg, the signal as text, so it stays readable: the deeper #c4310f on paper and the brighter #ff5233 on ink. Forced colours map every part to CanvasText.

/* A partner splash that needs a quieter mark */
.partner .lockup { --lockup-accent: var(--color-fg); --lockup-product: var(--color-fg); }

Accessibility

Role and pattern

As the Home link: a native <a href> with aria-label="Home", the lockup inside aria-hidden="true" (APG Link pattern). Standalone: role="img" aria-label="Telo Ride" on the .lockup span, so the SVG and the wordmark letters are read once as the product name (APG Names and descriptions).

Keyboard

KeyAction
TabMoves to the Home link (the first stop after the skip link). Static lockups are not focusable.
EnterFollows the Home link.

Focus

The shared 2px ring with a 2px offset sits on .app-header__brand, which has --radius-md corners so the ring follows the lockup instead of a sharp box.

Labelling

Exactly one name per lockup: “Home” for the link, “Telo Ride” for a standalone lockup. Never put aria-label on a plain <span>: a generic element cannot be named and screen readers skip it (the mocks do this; see Sources).

Motion

Logos are exempt from 1.4.3, but the pairs above keep the mark recognisable at 3:1. The lockup never animates.

Touch

The Home link is the lockup’s full box: 26px tall and about 116px wide at medium, above the 24px minimum. On phones it stays the first target in the header with 24px to the next control.

Content

  • In running text the product is “Telo Ride”: title case, two words. Only the lockup sets “TELO” in capitals.
  • Never rebuild the wordmark in another font or set “Telo Ride” in text next to the lockup; the lockup already says it.
  • The repository and specs still say Wattzup (mocks README, open question 1). The lockup follows the design: Telo Ride.
  • Alt text for a standalone lockup is “Telo Ride”, never “logo” or “Telo Ride logo”.
