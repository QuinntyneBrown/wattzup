Checkbox

A checkbox says yes or no to one thing that takes effect when the form is sent: attach diagnostics to a bug report, include the bike log. It is a real input, drawn as a 16px box that fills volt when checked.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Use a checkbox for an independent yes/no that is submitted with a form ("Attach diagnostics" in Send feedback). Use a switch for a setting that takes effect at once ("Ride along to a video"). Use radios when exactly one of several must be chosen.

Several related checkboxes go in a <fieldset class="choice-group"> with a <legend>. A parent checkbox that controls children shows indeterminate when only some are checked.

Anatomy

  1. BoxNative <input type="checkbox">, 16px, --radius-sm, 1px --color-line-strong border on ink; checked fills --color-volt with an ink tick.
  2. Label14px medium, 12px from the box; the whole <label> is the target.
  3. Hint (optional)14px --color-muted under the label, inside the same label.

Variants

Single, with hint; single, label only.

Group with an indeterminate parent (live)

Toggle the children: the parent shows the bar when some are on, the tick when all are, and checks or clears them all when pressed.

Horizontal group

Send with your report
Short labels may sit in a row (--horizontal); they wrap at 360px.

Sizes

One size: a 16px box with a 14px label. The label row, not the box, is the touch target.

Active shows the value the press lands on (the box flips on release). Invalid applies to a required consent or a group where at least one is needed; it comes with an error line under the group.

Both themes

Responsive behaviour

WidthRule

Theming

.checkbox (shared with .radio) declares --choice-size, --choice-bg, --choice-border, --choice-border-hover, --choice-on and --choice-mark. Volt and its ink tick are the same in both themes; the empty box is an ink well with a 3:1 border on paper and on panel.

Accessibility

Role and pattern

Native <input type="checkbox"> inside its <label>; groups in <fieldset> + <legend>. A parent uses the DOM indeterminate property (announced as "mixed") and aria-controls listing its children, as in the APG Checkbox pattern (mixed-state example).

Keyboard

KeyAction
TabMoves to each checkbox in turn (every checkbox is a tab stop).
SpaceToggles. On a parent: checks all children, or clears all when all were checked.

Focus

The shared ring around the 16px box at a 2px offset.

Labelling

The label wraps the input, so the text names it and clicking the text toggles it. Hints sit inside the label and become part of the name; keep them short. The group's legend is read when entering the group.

Motion

The tick scales in over --duration-fast; instant under reduced motion.

Touch

The full label row is the target (at least 24px tall; 20px line plus the hint). Keep 12px between rows.

Content

  • Label the thing that will be true when checked: "Attach diagnostics", not "Don't attach diagnostics".
  • Use the hint to say what it involves: "Bike connection log and app version, so we can reproduce it."
  • Legends name the set: "Send with your report".
