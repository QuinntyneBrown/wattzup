Slider

The slider sets a resistance level from 1 to 32 by dragging: "Work resistance 24 / 32", "Recover resistance 6 / 32". It is a native range with a big readout above it, and minus and plus buttons beside it for anyone who cannot drag.

Overview

Use .range inside a .level-slider when the rider picks a level on a wide scale and the rough position matters more than the exact number: work and recover resistance on Custom Setup, the single level on a flat ride. Use a number stepper when the rider nudges a value in fixed units (minutes, rpm), and type it into a text field only when the exact value must be typed.

Dragging is never the only way: the native range already moves with arrow keys, and .slider-row adds minus and plus buttons so a single tap changes the level by one (WCAG 2.5.7 Dragging Movements).

Anatomy

  1. Label.level-slider__label, a real <label for>, 14px muted.
  2. Readout30px display numeral plus a faint "/ 32"; hidden from assistive tech (the range announces its own value).
  3. FillNative track up to the thumb in accent-color: volt, or --color-rest for recover.
  4. ThumbBrowser-drawn in the accent colour; the input is 24px tall (--target-min).
  5. Scale"Light" and "Max" at the ends, 11px faint, decorative.

Sizes

The track is one size (full width, 24px tall input). Only the readout scales: default 30px (--font-size-3xl) for paired sliders, --large 60px (--font-size-6xl) when one level is the whole screen's decision.

Responsive behaviour

WidthRule
360 (base)Full width; on a 320px track each of the 32 levels gets about 10px, so the step buttons matter most here. The readout stays on the label's line.
640 (sm)No change; the setup column is 36rem.
1024 (lg)Sliders sit in the setup form beside the plan preview; never wider than 36rem, so a drag stays precise.

Theming

The range sets only accent-color (--color-volt, or --color-rest with --rest) and lets the browser draw the rest, so it follows the page's color-scheme: the unfilled track is the browser's own light or dark grey. Volt and rest keep their meaning in both themes: volt is effort, rest is recovery, as on the plan chart and the ride.

Accessibility

Role and pattern

Native <input type="range"> (implicit slider role) with min, max, value, and aria-valuetext="Level 24 of 32" so the level is read in words. Follows the APG Slider pattern for free. Step buttons are separate <button>s for 2.5.7.

Keyboard

KeyAction
→ ↑ / ← ↓Up / down one level.

Focus

The shared 2px ring around the whole input (24px tall), not only the thumb.

Labelling

Visible <label for>. The big readout and the Light/Max scale are aria-hidden: the range's own value text carries them. Step buttons are named for what they change: "Lower resistance level" / "Raise resistance level".

Motion

None of its own. The readout changes as the thumb moves, without animating.

Touch

The input is 24px tall (--target-min); the step buttons are 40px. On phones the thumb is easier to grab than the track, which is why the buttons sit beside it.

Content

  • Label the quantity, not the action: "Work resistance", "Recover resistance", "Resistance level".
  • Show the level as "24 / 32" so the rider knows the range; ends read "Light" and "Max", not numbers.
  • A note can tie the setting to the ride: "You can still nudge the level mid-ride from the dashboard."
