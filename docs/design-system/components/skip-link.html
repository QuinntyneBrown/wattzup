Skip link

The first thing a keyboard reaches on every page. Invisible until focused, then a volt chip in the top-left corner that jumps straight past the header to the page's content.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Every Telo Ride page, including each dialog mock, starts with <a class="skip-link" href="#main">Skip to content</a> before the header. A keyboard or switch user presses Tab once, sees it, presses Enter and lands on <main id="main"> instead of tabbing through the brand, four nav links, the level link and full screen on every screen (WCAG 2.4.1).

It is the one place volt fills a control that is not the primary action, because when it shows it is the primary action for that moment. It needs no design decisions per page: same text, same target, same place.

Anatomy

  1. Link"Skip to content", 16px semibold ink on volt, 8 × 12px padding, --radius-lg.
  2. PositionAbsolute, 16px from the left, 8px from the top, above everything (--z-tooltip). Moved up out of view (translate: 0 -200%) until focused.

Variants

One link, one label, one target: every page skips to its main landmark. Pages with a second long run of controls (the ride dashboard) rely on landmarks, not extra skip links.

Sizes

The skip link has one size; it uses the body type size so it reads at a glance.

  • Hidden is still in the accessibility tree and the Tab order; it is moved, not display: none.
  • Focus slides it in at once; it uses :focus (not only :focus-visible) because nothing but the keyboard can reach it. The volt fill is its own focus indicator: 3:1 against the ink page.
  • Hover only happens while it is shown; the fill lifts to --color-volt-hover like a primary button.
  • After activation focus is on main (it has id="main"; give it tabindex="-1" where a browser does not move focus to a non-focusable target).

Responsive behaviour

The same at every width: 16px from the left edge, which matches the 16px page margin under 640px. It is short enough ("Skip to content", about 140px) never to wrap at 360px. It sits above the header row, so it never covers the control that would receive focus next.

Theming

Reads --color-volt and --color-on-fill, which are the same in both themes (ink on signal orange, about 5.7:1). Nothing to re-theme; a partner theme that changes volt changes it too.

Accessibility

Role and pattern

A plain in-page link to #main (WCAG technique G1); the APG has no widget for it. Pair it with the landmarks (header, nav, main) the APG landmark regions practice describes.

Keyboard

KeyAction
Tab (first press)Focuses and shows the skip link.
EnterMoves focus to main; the next Tab reaches the first control in the content.
Tab againHides it and continues to the header's brand link.

Focus

It must be the first focusable element in the DOM, before .app. On dialog screens (Diagnostics, Leave this ride, Send feedback) the page behind is inert and main is the dialog, so the skip link lands inside it.

Labelling

The text is the name: "Skip to content". Do not add aria-label.

Contrast

Label on volt
Volt chip against the page

Motion

No transition: it appears instantly on focus so nobody waits to read it.

Touch

Touch users never see it (it needs keyboard focus). It is 40px tall when shown, above the 24px minimum for switch and pointer users.

Content

Always "Skip to content". Not "Skip navigation" (on task screens there is no nav to skip), not "Skip to main content" (longer for no gain).
