Number stepper

A number stepper nudges a value up or down by a fixed amount: 30 seconds on an effort, a minute on the warm-up, 5 rpm on the cadence goal. The value sits large between two square buttons, so the rider sees the result of every tap.

Overview

Use a stepper when the value moves in known steps inside a known range and the rider usually wants a nearby value: the interval ladder on Custom Setup, warm-up and cool-down, a flat ride's duration and cadence goal, the video offset ("Half a second earlier"). Use a slider when the range is wide and position matters (resistance 1–32), and a text field when the rider knows the exact value to type.

Three sizes share one anatomy: .mini-stepper (28px buttons, inside dense rows like the interval ladder), .training-stepper (40px, a labelled setting), and .training-stepper--ride (48px, anything pressed during a ride).

Anatomy

  1. Label14px muted; names the group (role="group" aria-labelledby).
  2. Decrease40px square .training-stepper__btn, raised, --radius-lg, minus icon.
  3. Value<output aria-live="polite">, 30px display numerals with tabular figures, unit inline ("30 min", "85 rpm").
  4. IncreaseSame button with a plus icon.

Theming

Buttons read --color-raised (hover --color-line) with --color-fg icons; the value is --color-fg in the display face. Raised sits one step above the panel in both themes, so the buttons read as pressable on paper and on ink.

Accessibility

Role and pattern

A role="group" named by its label, holding two named buttons and an <output aria-live="polite"> so each change is read ("5:30"). This is the simpler alternative to the APG Spinbutton pattern: two plain buttons are easier on touch and need no custom keys. Where the value can be typed (the video offset), the field is a labelled <input>.

Keyboard

KeyAction
TabDecrease button, then increase button (the output is not a tab stop).
Enter / SpaceOne step; held, the key repeats.

Focus

The shared ring around each square button at a 2px offset. At a limit the button keeps focus (aria-disabled) instead of dropping it to the page.

Labelling

Buttons are named for the direction and the setting: "Shorter warm-up", "Longer effort 1", "Half a second earlier". The group label names the setting once for the screen reader.

The button fill against the page is below 3:1, which 1.4.11 allows because the icon, not the fill, identifies the control.

Motion

Active scale over --duration-fast; none under reduced motion.

Touch

28px mini buttons clear 24px (2.5.8) with 6px between them; use them only in dense rows. Setup screens use 40px, ride screens 48px.

Content

  • Times as m:ss ("0:30", "5:00"); durations with a unit ("30 min"); cadence "85 rpm".
  • Button names in sentence case, direction first: "Shorter warm-up", not "Less Warm-up".
  • Say the step when it is not obvious, in the hint or the button name ("Half a second earlier").

Drift fixed during extraction:

  • custom-setup/*: the value is a plain <span>, so changes are silent; it is an <output aria-live="polite">.
  • custom-setup/*: buttons named "Less Warm-up" / "More Cadence goal" (title case pasted into a template); renamed in sentence case with a real direction ("Shorter warm-up", "Higher cadence goal").
  • custom-setup/default: the ladder's mini steppers are not grouped (no role="group"); added, named "Effort 1" / "Recovery 1".
  • Kit: .mini-stepper__btn:disabled and .training-stepper__btn:disabled are the only limit style, and disabled drops focus when the limit is reached; no mock shows a limit, so forms.css adds an aria-disabled style for it.
  • custom-setup/default: the offset value is a borderless text input with its label above the whole row; it becomes a labelled .input.
