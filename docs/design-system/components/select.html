Select

A select picks one value from a list too long for a segmented control: which group session to join, which bike you ride. It is the browser's own control dressed as a Telo field, so it keeps the phone's native picker.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

The mocks have no select yet. Use one when the rider picks one of five or more known options and the options are short: the next group sessions for a class (they start every 15 minutes), or the bike model when pairing finds an FTMS bike Telo Ride cannot name. Two to four options read better as a segmented control or a radio group; anything the rider types is a text field.

Always the native <select>, wrapped in .select (which draws the chevron). A custom listbox is only for a need the native control cannot meet (rich rows, search), and then follows the APG Listbox pattern.

Anatomy

  1. Label.field__label via <label for>.
  2. ControlNative <select class="select__control"> with appearance: none: ink well, 1px --select-border (3:1), 40px, --radius-lg, 14px value.
  3. ChevronDrawn by .select::after from two 2px borders in --select-chevron; decorative and click-through.

Variants

We found EX5S-0bf669f1 but couldn't tell which model it is.

With a chosen value; with a placeholder option (value="", disabled selected, shown faint while required and empty); raised.
HTML
<div class="field">
  <label class="field__label" for="bike">Your bike</label>
  <div class="select">
    <select class="select__control" id="bike" required>
      <option value="" disabled selected>Choose your bike</option>
      <option>Echelon EX-5s</option> …
    </select>
  </div>
</div>

Sizes

--select-height from --control-height-sm/md/lg; large steps the value to 16px and the padding to 16px. Match the size of the fields beside it.

States

VariantDefaultHoverFocusDisabledPlaceholderInvalid
Select
Raised

Open is drawn by the browser and the OS (a native list on desktop, a wheel or sheet on phones); color-scheme from the theme makes it dark in dark and light in light, and options read --color-panel where the browser allows.

Both themes

Responsive behaviour

WidthRule
360 (base)Full width of the form column; phones open their own picker, so the list never overflows the page. Long option text truncates in the closed control with the chevron kept clear (right padding 36px).
640 (sm)A select beside a short field may take a fixed width in a .form__row.
1024 (lg)Capped by the form column.

Theming

.select declares --select-bg, --select-border, --select-border-hover, --select-radius, --select-height, --select-chevron, --select-pad and --select-font-size, aliasing the same semantic tokens as .input, so a select and a text field side by side match in both themes. Sizes and --raised only change tokens.

Accessibility

Role and pattern

Native <select> (implicit combobox/listbox role); no ARIA needed. A custom version must follow the APG Listbox (or Combobox) pattern in full.

Keyboard

KeyAction
TabFocuses the select.
Space / Enter / Alt+↓Opens the list.
↑ ↓Moves through options (changes the value directly while closed on Windows).
A letterJumps to the next option starting with it.
EscCloses the list without changing the value.

Focus

2px ring flush with the border (offset 0), like the text field.

Labelling

<label for>. The placeholder option is not a label: it is disabled so it cannot be chosen back. Changing the value never navigates or submits by itself (3.2.2); "Join" does that.

Motion

None of its own; the OS animates the picker.

Touch

40px tall, whole control is the target; the phone's picker gives full-size rows.

Content

  • Placeholder options start with a verb: "Choose your bike".
  • Options are short and lead with what differs: "7:39 PM · starts in 9 min", "Medium · around 190 W".
  • Order by time, size or the order the rider meets them; alphabetical only when nothing else applies.
