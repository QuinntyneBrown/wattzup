Tabs

Tabs switch between views of the same thing without leaving the page. The Class Library's length tabs are the product's one tab list; underline tabs are the quieter form for sections inside a page.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Use tabs when every view answers the same question in a different cut (all classes, or only the 20-minute ones) and the rider will flip between them. Do not use them:

  • to go somewhere else: that is a link or the app header;
  • to pick a setting that changes what happens next (pack strength, ride alone or together): that is a segmented control or radio cards;
  • for steps in order: they would invite skipping.

Pill tabs (.tier-tabs) are the design's: a raised track with the selected tab in bone, used at the top of a page beside its title. Underline tabs (.tabs) are an addition for sections inside a page, where a filled track would shout; they share the APG behaviour.

Anatomy

  1. Track (tablist)role="tablist" with a name; raised fill, 8px radius, 4px padding. Scrolls sideways when it does not fit.
  2. Selected tabBone fill (--color-fg) with ink text, 6px radius; aria-selected="true", the only tab in the Tab order.
  3. Tab14px medium, muted; 6 × 14px padding, 32px tall. Underline tabs add a 2px volt bar under the selected one and an optional count.

Scrollable

.tabs--scroll fades the trailing 32px; the list scrolls sideways (trackpad, touch, or the arrow keys, which scroll the selected tab into view). Tabs never wrap to a second row.

Sizes

Pill 32px (6px padding + 20px line, inside a 40px track) · underline .tabs--sm 36px (--control-height-sm) · underline 40px (--control-height-md, default).

States

VariantDefaultHoverFocusActiveSelectedDisabled
Pill
Underline
  • Selected is aria-selected="true": bone fill on the pill, fg text and a volt bar on the underline. Exactly one tab per list.
  • Disabled uses aria-disabled="true", not disabled, so the tab stays reachable with the arrow keys and its name is still read. Prefer an enabled tab with an empty panel ("No 60-minute classes open yet") over a disabled one.
  • Focus draws the ring inside an underline tab (the list scrolls and would clip it) and outside a pill tab (the track's 4px padding leaves room).

Both themes

Responsive behaviour

  • Under 640px: the Class Library head wraps, so the pill tabs sit under the title and lead, left-aligned. Four length tabs fit in 360px; more than that scroll inside the track (overflow-x: auto, no scrollbar).
  • Underline tabs scroll sideways at every width and never wrap; add .tabs--scroll to fade the trailing edge so a half-shown tab reads as "more this way". Selecting a tab scrolls it into view.
  • From 640px the pill tabs sit beside the title, bottom-aligned with the lead (.library-head: flex-wrap, align-items: flex-end).
  • Tab labels do not truncate; shorten the label instead ("20 min", not "20-minute classes").

Classes

Theming

Pill: track --color-raised, tab text --color-muted lifting to --color-fg, selected tab --color-fg fill with --color-ink text (the same inverse pair as the preset chips and pack-strength control). Underline: hairline --tabs-border (--color-line), selected bar --tabs-indicator (--color-volt, "selected" being one of volt's three jobs). Re-theme by overriding the --tabs-* tokens on .tabs.

/* Gold indicator for an achievements page: earned things only */
.tabs--earned { --tabs-indicator: var(--color-gold); }

Accessibility

Role and pattern

APG Tabs with automatic activation: moving to a tab selects it and shows its panel, because every panel here is already in the page (a filter of one list). role="tablist" with aria-label; each <button role="tab"> has aria-selected and aria-controls; each panel is role="tabpanel", aria-labelledby its tab and tabindex="0" when it starts with text rather than a control.

Keyboard

KeyAction
TabInto the list, landing on the selected tab (roving tabindex: 0 on it, −1 on the rest); next Tab moves to the panel.
← / →Previous / next tab, wrapping at the ends; selects it and shows its panel. Disabled tabs are focused but not selected.
Home / EndFirst / last tab.
Enter, SpaceSelects the focused tab (needed only for a disabled-then-enabled tab; arrows already select).

Focus

Shared ring on :focus-visible: outside the pill tab, inset on the underline tab. The panel shows the ring 4px outside itself when focused.

Labelling

The tablist is named for what the tabs cut by ("Class length"). A count inside a tab is part of its name ("30 min 3"); when that reads badly, give the count aria-hidden="true" and add it in words in visually hidden text ("30 min, 3 classes").

Motion

Text and fill colours ease over --duration-fast; the bar appears in place, it does not slide. Reduced motion makes both instant.

Touch

Pill tabs are 32px tall and at least 46px wide ("All"), above the 24px minimum; underline tabs are 36–40px. Horizontal scroll works with a swipe; there are no hover-only affordances.

Content

  • One to three words, sentence case, no verbs: "All", "20 min", "Recent rides".
  • "All" comes first when the tabs filter one list.
  • Counts are numerals for what the panel holds now, never "new" badges.
  • Do not repeat the list's name in every tab ("20 min classes", "30 min classes").

Code

// Automatic activation with a roving tabindex (vanilla, ~15 lines)
list.addEventListener('keydown', (e) => {
  const tabs = [...list.querySelectorAll('[role="tab"]')];
  const i = tabs.indexOf(document.activeElement);
  const next = { ArrowRight: i + 1, ArrowLeft: i - 1, Home: 0, End: tabs.length - 1 }[e.key];
  if (next === undefined) return;
  e.preventDefault();
  select(tabs[(next + tabs.length) % tabs.length]);
});
function select(tab) {
  tab.focus(); tab.scrollIntoView({ block: 'nearest', inline: 'nearest' });
  if (tab.getAttribute('aria-disabled') === 'true') return;
  for (const t of list.querySelectorAll('[role="tab"]')) {
    const on = t === tab;
    t.setAttribute('aria-selected', on); t.tabIndex = on ? 0 : -1;
    document.getElementById(t.getAttribute('aria-controls')).hidden = !on;
  }
}
