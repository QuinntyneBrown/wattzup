Plan chart

A plan chart shows what the bike will do before and during a ride: one bar per segment, as wide as the segment is long and as tall as its resistance level. Slate for warm-up and cool-down, volt for work, blue for recovery.

Overview

Every structured ride in Telo Ride has a plan: a list of segments, each with a kind, a length and a resistance level (shared/workout.ts). The plan chart draws that list. It answers "how hard, and when?" at a glance and is the same drawing everywhere the plan appears:

  • Class card (.class-profile, 20px): under every cover in the Class Library, so riders can tell a pyramid from an endurance ride before opening it. See Class card.
  • Class Start (.class-plan + .class-profile--lg, 80px): "What the bike will do", with the total and a one-line summary.
  • Class ride (.class-segment): the current segment's kind, countdown and fill bar above the profile, so the rider sees where they are in the whole plan.
  • Custom workout (.plan-preview, 144px): "Your ride", the live preview beside the settings, with facts and a legend. The .interval-ladder that edits it uses the same kind swatches.

Use a ride trace to compare live power with the plan, and a route profile for elevation on a map. Do not use a plan chart for anything that is not a plan: it has no y-axis values, only relative levels.

Anatomy

  1. Label14px medium, muted: "What the bike will do", "Your ride".
  2. TotalBarlow Condensed 24px (60px in the preview), tabular figures, m:ss.
  3. Warm-up and cool-down bars--color-plan-easy (slate) at 50% opacity, so they read as "not the work".
  4. Work bars--color-volt; steady segments in a flat plan use the same colour.
  5. Recover bars--color-rest. Height is the level out of 32; width is the length in seconds in a 0 0 <total> 32 viewBox stretched to the box (preserveAspectRatio="none"). Bars are inset 3.6 units each side so neighbours never touch.
  6. Text alternativeThe visible summary line, the SVG's aria-label, and an optional .ride-data table with every segment.

Variants

One drawing, four settings. Pick by what the rider is deciding: browsing (card), committing (Class Start), riding (segment) or building (preview).

Responsive behaviour

  • 360px: every profile is the full width of its column; the 30-second efforts are about 5px wide and still read because of their height. The class ride's segment panel spans both columns of the bike grid (.class-stat--wide). The preview sits under the settings with a hairline on top; its legend wraps.
  • 640px: class cards go two up, so card profiles halve in width with no change in height. Ladder rows keep their four columns (24px · 1fr · 1fr · 32px).
  • 1024px: Class Start puts the plan in the left column (max 42rem); the preview becomes a 420px aside with a hairline on the left (--setup-preview-width) and pins its legend and Start to the bottom (mt-auto). Class cards go three up.
  • Heights never change with width. Tick labels thin out below 480px: keep the first, middle and last.

Theming

The chart reads three colour decisions and nothing else: --color-volt (work, steady), --color-rest (recover) and --color-plan-easy (warm-up and cool-down). They are theme-independent: the same orange, blue and slate sit on ink and on paper, so a plan looks the same in both themes. The area tokens --classes-segment-easy, --dashboard-segment-easy and --race-segment-easy all alias --color-plan-easy; new code reads the semantic name.

/* Any part that draws a segment reads --kind; set it with a class, never a raw colour */
.ride-kind--warmup, .ride-kind--cooldown { --kind: var(--dashboard-segment-easy); }
.ride-kind--work, .ride-kind--steady { --kind: var(--color-volt); }
.ride-kind--rest { --kind: var(--color-rest); }

On paper, volt on a white panel is 3.4:1 and blue 3.4:1, just over the 3:1 a graphical object needs; slate at 50% is lighter still and is treated as decoration (the kind is in the summary text and table).

Accessibility

Role and pattern

The SVG is one image: role="img" with an aria-label that describes the shape ("5 minute warm-up, eight 30-second efforts at level 24 …"), not just "Resistance profile". Its long description is the visible summary line plus a .ride-data table in a native <details>, following the W3C complex images tutorial and the APG disclosure pattern. Individual bars are not focusable.

Keyboard

KeyAction
Tab / Shift+TabSkips the chart; reaches the table summary, then the ladder's steppers and remove buttons, then Start ride.
Enter, SpaceOpens or closes the table; activates a stepper or remove button.
EscNo effect.

Focus

The table summary and ladder buttons take the shared ring (2px --color-focus-ring, 2px offset). When a round is removed, focus moves to the next round's remove button, or to "Add round" when the last one goes.

Labelling

The table has a caption naming the plan and its length; rows are segments with a row header ("Recover 3"), columns Starts, Length, Level. During a ride the current row has aria-current="step". Legends are aria-hidden: the table and the label already say which colour is which. Ladder buttons name the round ("Shorter recovery 2", "Remove round 3").

Motion

Nothing in the chart moves. The current segment's fill grows linearly over each second (--duration-countdown); under prefers-reduced-motion it steps once a second instead of easing.

Touch

The chart is not a target. Ladder mini-steppers are 28px with 6px between them: above the 24px minimum, below the 44px comfortable size, acceptable because the ladder is edited before a ride, never during one. Colour is never the only cue: work bars are also tall, recover bars short, warm-up and cool-down sit at the ends.

Content

  • Kinds are named Warm-up, Work, Recover, Cool-down and Steady in every label, legend and table. The CSS says rest; the copy never does.
  • The summary line follows one formula: rounds × effort · first recovery → last recovery recover · ~average W average: "8 × 0:30 · 3:00 → 1:30 recover · ~154 W average". A flat plan says "Level 12 throughout".
  • Times are m:ss (0:30, 30:00), never "30 sec". Estimates carry a tilde: "~154 W", "~276 kcal".
  • Levels are "Level 24" in facts and "of 32" beside a stepper; never a percentage.
