Tooltip

A one-line label for a control that shows only an icon or a terse status. It appears on hover and on keyboard focus, never holds anything to click, and replaces the browser's title tooltip the mocks rely on.

WCAG 2.2 AAStatus: stableSince v1.0

Overview

Telo Ride has icon-only controls on every ride screen (Full screen, the bike status, the collapsed sidebar). The mocks label them with title="…", which shows late, never on keyboard focus, never on touch, and cannot be styled. This tooltip is the replacement.

  • Use it to repeat an icon button's name ("Full screen") or expand a terse status ("Bike not connected").
  • Never put the only copy of important information in a tooltip; never put links, buttons or anything to select in one (use a popover).
  • Do not add a tooltip to a control that already shows its label.

Anatomy

  1. Label12px medium, inverse (--color-bg-inverse / --color-fg-inverse), 6px × 10px padding, 8px radius, max 240px, wraps.
  2. Shortcut (optional)A .tooltip__key keycap when the action has a key.
  3. AnchorThe control it describes; 8px gap, a hover bridge fills it so the pointer can move onto the tooltip.

Appears after a 300ms rest on hover or focus; disappears at once on leave or blur, and on Esc without moving focus.

Sizes

One size: 12px text, at most 240px wide (--tooltip-max). Longer text means it belongs on the page or in a popover.

States

AnchorDefaultHover (after 300ms)Focus (after 300ms)ActiveDismissed (Esc)Disabled
Icon button Full screen Full screen Full screen Full screen hidden on press Full screen Full screen needs a video
  • Hover / focus: shown after --tooltip-delay (300ms) so sweeping the pointer across the ride header does not flash labels; hidden immediately.
  • Active: pressing the control hides its tooltip; it should not cover the result.
  • Dismissed: Esc sets data-dismissed on the anchor until the pointer leaves or focus moves (WCAG 1.4.13).
  • Disabled: a native disabled button gets no hover or focus, so its tooltip never shows. To explain why something is unavailable, use aria-disabled="true" (still focusable), as here, or better, say it on the page.

Both themes

Full screen F
Full screen F

Inverse in both: bone on ink in dark, ink on paper in light, so it reads over the page, over panels and over photos and video.

Responsive behaviour

  • Touch screens have no hover: a tooltip shows on focus only, which a tap does not reliably give. So every control must have a visible or accessible label without it; on touch the tooltip is a bonus.
  • Near a screen edge use .tooltip--start or --end so it never runs off; max width is 240px, under the 328px usable at 360px.
  • In the full-screen ride view (no header), keep tooltips for the controls bar; they sit above it.

Theming

Block tokens: --tooltip-bg (--color-bg-inverse), --tooltip-fg (--color-fg-inverse), --tooltip-max, --tooltip-gap, --tooltip-delay. Do not tint tooltips by tone; a warning belongs in an alert.

Accessibility

Role and pattern

APG Tooltip: role="tooltip", referenced from the control by aria-describedby. For an icon-only button the accessible name is its aria-label ("Full screen"); the tooltip repeats it visually and is the description only when it adds something (the shortcut). When it would only repeat the name, mark it aria-hidden="true" and drop aria-describedby (as in the collapsed sidebar), so it is not read twice.

Keyboard

KeyAction
TabFocusing the control shows its tooltip after 300ms; moving on hides it.
EscHides the tooltip without moving focus.

Focus

The tooltip never takes focus. It is shown by :focus-within on the anchor, so it works for keyboard users without script; script only adds Esc.

Labelling

Content is plain text, at most one short line plus a key; no headings, links or images. The tooltip's text and the control's name must match (WCAG 2.5.3 Label in Name).

Motion

Fades in over --duration-fast after the delay, out at once. Reduced motion: no fade. The 300ms delay is about intent, not motion, so it stays: --tooltip-delay reads --duration-delay-tooltip, which reduced motion leaves alone.

Touch

Hoverable and persistent (1.4.13): the pointer can move onto the tooltip through an invisible bridge over the gap, and it stays until the pointer leaves, focus moves, or Esc.

Content

  • The control's name, sentence case, no full stop: "Full screen", "Send feedback".
  • A status in a few words: "Bike not connected".
  • At most one line of about 40 characters; the shortcut in a keycap.

// Esc hides the tooltip until the pointer leaves or focus moves
document.addEventListener('keydown', e => {
  if (e.key !== 'Escape') return;
  const a = document.activeElement?.closest('.tooltip-anchor') ?? document.querySelector('.tooltip-anchor:hover');
  if (a) a.dataset.dismissed = '';
});
document.addEventListener('focusout', e => e.target.closest('.tooltip-anchor')?.removeAttribute('data-dismissed'));
document.addEventListener('pointerout', e => e.target.closest('.tooltip-anchor')?.removeAttribute('data-dismissed'));
