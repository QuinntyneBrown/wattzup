Video

The box the class video plays in: reserved before it loads, locked to the ride clock while it plays, and honest about pausing.

Overview

Video frames hold the YouTube player that classes and custom rides follow. The bike follows a plan locked to the video’s clock, so the frame matters: it reserves a 16:9 box before the player loads and shows the class cover until it does. The mocks draw the cover in every frame; this page says what plays in each.

  • Class Start (.class-start-video): the player with its controls, loaded and parked 0:12.0 in (the class’s sync offset) so the rider can preview.
  • Class Ride (.class-video): the player without controls, playing from the ride clock plus the offset (7:12 at 7:00). Pause shows a “Paused” overlay; a group ride has no pause.
  • Custom ride (.ride-video): the rider’s own video, letterboxed (contain) on a video-black stage, in the “Video” tab; it re-seeks when it drifts more than 1.5s and pauses with the ride.
  • Video sync (.video-sync, Custom setup): paste a YouTube link, preview it with controls, set where ride 0:00 falls in the video.
  • Not for decorative motion or the 3D world (that is the race scene).

Anatomy

  1. Frame16:9 box, --radius-xl (--radius-2xl on Class Start), raised well until the player paints.
  2. Player / coverThe YouTube iframe; before it loads, the class cover cropped to 16:9 with .photo--yt.
  3. Paused overlayInk at 70% over the picture, “Paused” 18px semibold, centred. Solo rides only.
  4. Waiting overlayA group ride before its session’s start: the same ink at 70%, “Starts in” 14px muted, the time left 36px display tabular in --color-volt-fg (role="timer"), and the start time in a muted note. The video is parked at its sync offset underneath.

Sizes

Width comes from the column; height from 16:9. From 1024px the Class Ride and custom ride frames drop the ratio and fill the column height beside the board and readouts. The offset input is 96px wide with 30px numerals.

Theming

The frame well is --color-raised (Class Start, Class Ride) or --color-video (custom ride, sync player: always black so letterboxing looks like video). The paused overlay mixes --color-ink at 70%, which in light becomes paper at 70% with ink text: still readable, and clearly “not playing”.

Accessibility

Role and pattern

The player is a YouTube <iframe> with title="30 Minute HIIT Cardio, GCN Training"; the cover image before it uses the same text as alt prefixed “Video:”. In Class Ride the iframe is tabindex="-1" and has no controls: the ride’s own Pause, Finish and Leave control it. The sync form uses native <label>s. (APG Button pattern for the stepper.)

Keyboard

KeyAction
TabClass Start: into the YouTube player (its own keyboard: Space plays, arrows seek). Class Ride: skipped. Sync: link → minus → offset → plus → Use video’s current time → Check.
SpaceClass Ride (solo): the ride’s Pause button pauses ride and video together.
EnterActivates the focused stepper or action.

Focus

The sync link and offset inputs show the shared ring; the link’s border also turns volt. Focus never moves into a Class Ride player.

Labelling

The paused overlay is announced by the ride’s status (“Paused”), not by the overlay. The waiting overlay’s time left is a role="timer" named “Starts in 9:00”; a timer is not announced on each tick. The offset buttons are named “Half a second earlier / later”. An invalid link sets aria-invalid and points aria-describedby at the error.

Motion

Video plays because the rider started a ride; nothing autoplays on a browse page. The paused overlay appears without animation. Reduced motion does not stop the class video (it is the content), but the cover never animates.

Touch

Offset steppers are 40px; the sync link is 44px tall (--target-comfortable).

Content

  • Alt and title: “Video: ” + class title + “, ” + channel.
  • Offset as m:ss.s: “0:12.0”; label “Ride 0:00 starts at”.
  • Overlay: one word, “Paused”.
  • Status line in the custom ride: “In sync · pauses with the ride”.
  • Never promise what the network cannot: when the video fails, say the bike still follows the class.
