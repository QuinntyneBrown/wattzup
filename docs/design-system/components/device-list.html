Device list

Find the bike, pair it, and say plainly when this computer or browser cannot.

Overview

The device list is the first-run pairing column on Connect Bike: one card for the bike Telo Ride has found (or is still looking for), the button that pairs it, a list of the bikes that work, and a blocker card when the browser or the computer cannot use Bluetooth.

  • Device card (.connect-device): searching → found → pairing → paired. One bike at a time: Web Bluetooth’s own chooser lists nearby devices; this card shows the one picked.
  • Pair button (.connect__pair-btn): the page’s one primary action; disabled while searching and after pairing, busy while pairing.
  • Works with (.connect-works): supported bikes and how well (Full control, Beta).
  • Blocker (.connect-blocker): replaces card and button when Bluetooth is off or the browser lacks Web Bluetooth.
  • Once paired, the bike lives in the app header (“Echelon EX-5s”) and in Profile’s settings row; this list is not shown again.

Anatomy

  1. Card--color-panel, --radius-xl, 16px padding.
  2. NameThe bike’s model, 16px semibold.
  3. SignalBars icon (volt) + “Strong signal · EX5S-0bf669f1” (strength · the device’s Bluetooth name).
  4. Paired tick24px volt check, role="img" aria-label="Paired"; paired state only.

Theming

Card and blocker are --color-panel; signal, spinner and tick --color-volt-fg; the blocker icon --color-heart-fg (Bluetooth off) or --color-warn-fg (browser); Beta --color-warn-fg; other statuses --color-faint. Disabled pair button: --color-raised with --color-muted text.

Accessibility

Role and pattern

The pair control is a link while a bike is found and a <button> otherwise (APG Button pattern). Searching is a role="status"; blockers are role="alert" sections named by their heading. Works-with is a plain list.

Keyboard

KeyAction
TabPair button (or the blocker’s action), then nothing else on the card.
EnterStarts pairing; opens the browser’s Bluetooth chooser.
EscCloses the browser’s chooser (the browser’s own); the card returns to found.

Focus

Focus starts on the page; after pairing fails, return focus to the pair button. The ring is the shared 2px ring on the 56px button.

Labelling

Name the bike in the button: “Pair Echelon EX-5s”. Announce the outcome in the status region: “Echelon EX-5s paired.” The signal icon is decorative; the text says the strength.

Motion

The spinner turns once per second (--duration-loop); under reduced motion it stops and the text carries the state.

Touch

Pair and blocker buttons are 56px and 40px tall, full width or 24px clear of neighbours.

Content

  • Searching: “Looking for bikes nearby…”; button “Searching…”. Pairing: “Pairing…”. Done: “Paired”.
  • Signal: “Strong signal · EX5S-0bf669f1”: strength, then the bike’s Bluetooth name as it advertises.
  • Blocker title says what is wrong (“Bluetooth is off”), the body says what to do in one or two sentences.
  • Works-with statuses: “Full control” or “Beta”. No “coming soon”.
