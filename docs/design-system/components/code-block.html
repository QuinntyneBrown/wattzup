Code block

Machine text, shown exactly so it can be read or copied into a bug report: the packet log, the diagnostics summary, a file name.

Overview

Code is machine text shown so someone can read or copy it exactly. Telo Ride shows it in one place, Diagnostics: the facts list sets its values in JetBrains Mono, and the packet log (.diagnostics__well) counts packets and downloads them as a .jsonl file. .code-block is the mono well that shows that log, or the diagnostics summary, with its file name and a Copy button; .code is inline code inside a sentence.

  • Use a code block for text people paste into a bug report: packet lines, a diagnostics summary.
  • Use inline .code for a file name, a URL or a command inside a sentence.
  • Do not use code styling for numbers people read (use stat) or for key-value facts (use a description list with .dl--mono).

Anatomy

  1. HeadFile name in 12px mono --color-muted, truncated; hairline under.
  2. Copy button.btn.btn--raised.btn--sm with copy icon; turns to a green check and "Copied" for 2 s.
  3. Code<pre><code> on --color-ink, 12px JetBrains Mono, 1.625 line height; scrolls both ways inside its 18rem cap and is focusable so the keyboard can scroll it.
  4. Foot (optional)What is shown versus what exists ("showing the last 4").

  • Copied: data-copied on the button swaps the icon to a check in --color-ok-fg and the label to "Copied"; the hidden role="status" says "Copied to clipboard". After 2 s it returns to Copy.
  • Disabled: nothing to copy yet (log empty, "Log every packet" off).

Responsive behaviour

  • 360px: the block is full width; lines do not wrap (except --wrap), the code area scrolls sideways inside itself; the file name truncates before the Copy button does.
  • 640px and up: no change; inside Diagnostics the block is capped by the dialog's 460px.

Theming

.code-block { --code-bg: var(--color-ink); --code-fg: var(--color-fg); --code-border: var(--color-line); --code-max-height: 18rem; }

The well is always the canvas colour, one step below the panel it sits in (ink in dark, paper in light), like the Diagnostics packet well.

Accessibility

Role and pattern

<pre><code>. The <pre> has tabindex="0" and an aria-label when it scrolls, so keyboard users can reach and scroll it. The copy button is a native <button>; the result is announced through a polite role="status".

Keyboard

KeyAction
TabCopy button, then the code area.
Enter, SpaceCopies.
← → ↑ ↓Scroll the focused code area.

Focus

The code area draws its ring inset (offset −2px) so the block's rounded clip does not hide it.

Labelling

The head names the file; the copy button's name is "Copy" (add the file when there are several: "Copy packet log"). Arrows in the log are characters screen readers announce as "right arrow"; the JSON also says "dir":"out".

Content

  • Show machine text exactly; never prettify values people paste into a report.
  • File names carry the date as the download does (telo-ride-packets-YYYY-MM-DD.jsonl).
  • The copy label is "Copy", then "Copied"; never "Copied!".
  • Say what is shown when it is an excerpt ("showing the last 4").
