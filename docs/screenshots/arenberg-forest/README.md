# Arenberg Forest from the saddle

Choose Arenberg Forest in Map Select and start a solo race. GCN’s *Don’t Get Dropped* has 22 stages over 25:00. The 10.725 km course climbs 34 m. The 2.4 km straight pavé runs from 0.32 to 2.72 km. The captures use a simulated bike at 90 rpm and the 1024 × 768 race HUD on Low/WebGL 2.
